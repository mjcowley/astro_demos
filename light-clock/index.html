The argument: a light clock ticks each time a pulse of light bounces between two mirrors. To Steve, standing still, the light in Michelle's moving clock has to travel along a slanted path, which is longer than the straight up-and-down path. Light moves at the same speed c for everyone (the second postulate), so a longer path takes longer: each tick of the moving clock takes more time. The triangle on the right gives the formula: (ct)² = (vt)² + (ct₀)², which rearranges to t = t₀ / √(1 − v²/c²) = γt₀. Michelle, riding with her clock, sees nothing strange: her clock ticks normally for her. The time t₀ measured by a clock moving with the event is the proper time.
The animation shows everything from Steve's frame, with light slowed right down so you can follow it. The calculator uses c = 299,792,458 m/s and, for everyday speeds, computes the tiny difference t − t₀ directly so it isn't lost to rounding.
